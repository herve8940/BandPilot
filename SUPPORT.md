# Assistance BandPilot / BandPilot help

- **Échanger avec les musiciens** : [communauté Discord](docs/COMMUNITY_FR.md), questions, astuces et idées en français ou en anglais.
- **Installer ou apprendre** : [téléchargements](https://herve8940.github.io/BandPilot/#download), [guide FR](docs/USER_GUIDE_FR.md), [guide EN](docs/USER_GUIDE_EN.md), [Android](docs/ANDROID.md).
- **Vérifier une console** : [capacités et limites](docs/multi-model.md). La détection d'un modèle ne valide pas toutes ses fonctions sur le matériel.
- **Signaler un bug ou une idée** : [formulaires GitHub](https://github.com/herve8940/BandPilot/issues/new/choose). Précise version, plateforme, console et reproduction ; relis les informations privées avant publication.
- **Signaler une vulnérabilité** : [procédure de sécurité](SECURITY.md).
- **Aider le projet** : [soutien et contributions](docs/SUPPORT_FR.md). Un soutien financier n'achète pas d'assistance prioritaire ni de délai garanti.

Install and learn with the [English site](https://herve8940.github.io/BandPilot/en.html#download)
and [guide](docs/USER_GUIDE_EN.md). Use issue forms for bugs and ideas, the security
procedure for vulnerabilities and the [support page](docs/SUPPORT_EN.md) to help the
project. Community assistance has no guaranteed response time.

Join the [Discord community](docs/COMMUNITY_EN.md) for questions, tips and conversations in French or English. Keep reproducible bugs and specific feature requests in GitHub Issues for tracking.
