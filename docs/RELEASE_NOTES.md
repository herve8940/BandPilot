# BandPilot 2.3.2

## Français

- **Ambiances récupérables.** Après un changement d’adresse, vérifie l’ambiance sur la console connectée avant de reprendre son suivi. Les réglages doivent correspondre ; aucune écriture audio n’est faite par cette vérification. Un ancien suivi peut aussi être archivé sans changer les effets de la console, y compris si sa source a disparu du groupe.
- **Ajout d’instruments et de musiciens fiabilisé.** La sélection d’un instrument reste une préparation locale. Les réglages sont préparés séparément, puis appliqués après confirmation. Les noms accentués sont acceptés, la navigation attend la sauvegarde et une lecture OSC perdue est retentée une seule fois sur la même connexion.
- **Fiche technique accessible immédiatement.** Un raccourci visible dans Mon ingé son ouvre directement la fiche, le plan de scène et les exports PDF. Les ambiances ont aussi leur raccourci.
- **Rapport de bug intégré.** Le bouton Signaler un problème prépare un fichier JSON avec version, fabrication, état et erreurs récentes. Aperçu et export fonctionnent sans envoyer de données. Après vérification du rapport, une connexion GitHub personnelle permet de créer directement une issue ; une option navigateur copie le rapport et ouvre le formulaire. Le dépôt est public. Aucun audio ni carnet de contacts n’est joint ; les secrets, adresses réseau et chemins personnels sont masqués.
- **Mises à jour proposées au lancement.** L’application vérifie les versions stables publiées depuis main et propose l’installateur de l’ordinateur lorsque celui-ci est disponible. Le téléchargement reste volontaire ; aucune installation ni interruption de session n’est automatique.
- **Version identifiable.** Le rapport et l’écran de support indiquent le commit et la date de fabrication. Chaque publication reçoit désormais un nouveau numéro de version.

## English

Recover ambience tracking after an IP change only when mixer readbacks match, or archive old tracking without changing audio. Adding instruments stays local; accented names, saved-step navigation and one safe read retry improve reliability. The technical rider and source ambience tools have visible shortcuts. A reviewed diagnostic report can be exported or sent as a GitHub issue using a personal encrypted credential; a browser fallback is available. Startup checks offer compatible stable installers published from main. Installation remains manual, and reports include the build identifier.

## Italiano

Recupera gli effetti dopo un cambio di indirizzo solo se i dati letti dal mixer corrispondono, oppure archivia il vecchio registro senza modificare l’audio. L’aggiunta di strumenti rimane locale; nomi accentati, salvataggio prima di avanzare e un solo tentativo aggiuntivo di lettura migliorano l’affidabilità. Scheda tecnica ed effetti hanno scorciatoie visibili. Il rapporto diagnostico può essere esportato o inviato a GitHub dopo verifica, con credenziali personali cifrate o tramite browser. All’avvio vengono proposti gli aggiornamenti stabili compatibili pubblicati da main; l’installazione resta manuale.

## Español

Recupera el seguimiento de ambientes tras un cambio de dirección solo si coinciden los ajustes leídos, o archiva el seguimiento anterior sin modificar el audio. Añadir instrumentos es una preparación local; se admiten acentos, se espera al guardado y se reintenta una lectura perdida. La ficha técnica y los ambientes tienen accesos visibles. El diagnóstico revisado se puede exportar o enviar como incidencia GitHub con credenciales personales cifradas o mediante el navegador. Al iniciar se ofrecen instaladores estables compatibles publicados desde main; la instalación sigue siendo manual.

## Deutsch

Effekte lassen sich nach einem Adresswechsel wieder zuordnen, wenn die ausgelesenen Einstellungen übereinstimmen. Alte Zuordnungen können ohne Audioänderung archiviert werden. Instrumente werden lokal vorbereitet; Akzente, Speichern vor dem Weitergehen und ein einmaliger Leseversuch bei Antwortverlust verbessern die Zuverlässigkeit. Technical Rider und Effekte sind direkt erreichbar. Geprüfte Diagnoseberichte lassen sich exportieren oder mit verschlüsselten persönlichen Zugangsdaten als GitHub-Issue senden; alternativ ist der Browser nutzbar. Beim Start werden kompatible stabile Installationsdateien aus main angeboten. Die Installation bleibt manuell.
